# ChronoCue 1.3.0

ChronoCue 1.3.0 makes everyday schedule management faster and adds portable,
human-editable preset files.

## Faster schedule editing

- Press **Enter** in the Time, Title, or Message field to save a valid schedule.
- Click a schedule's **Status** cell to toggle it immediately, or select one row
  and press **Space**.
- Clearly distinguish **Enabled**, **Paused**, and **Preset off** states.

## Editable preset files

- Export a ready-to-edit preset template.
- Export an existing preset and its schedules without internal IDs.
- Preview and validate imports before the configuration changes.
- Generate fresh IDs, start imported presets inactive, and preserve existing
  presets by importing name conflicts as copies.
- Write exports and configuration changes atomically.

## Naming and upgrade safety

- Use `~/.config/chronocue/config.json` as the standard configuration path.
- Preserve and copy an existing `schedule.json` during installer migration.
- Remove remaining Time Threshold Alerts wording and keep notification titles
  centrally formatted as `[ChronoCue] <title>`.

## Upgrade

From the repository checkout:

```bash
./scripts/install.sh
```

The installer preserves existing schedules and restarts `chronocue.service`.
